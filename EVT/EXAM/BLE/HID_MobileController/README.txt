HID_MobileController

BLE HID 遥控器例程。手机通过 BLE 连接后，按键会被识别为 Android 触摸屏/音量键操作，可用于刷视频、拍照等场景。

功能：

- 设备名 HID MobileController，BLE HID 从机，支持配对绑定。
- 方向键：上/下/左/右滑动。
- 中间键：点击。
- 上/下键长按：音量 +/-，按住可连发。
- 拍照键：在配置的屏幕点位按下/松开；按住拍照键时用方向键移动点位，松开后约 5 秒自动保存到 DataFlash；按住拍照键时按中间键可恢复默认点位。
- 广播时 PB4 LED 闪烁，连接后停止闪烁；60 秒未连接自动进入 shutdown，按任意键唤醒并复位。
- 调试串口 UART0：PA14(TX)/PA15(RX)，115200。

引脚：

下 / 拍照 / 右 / 上：PA4 / PA5 / PA12 / PA13
左 / 中间：PA8 / PA9
LED：PB4
调试串口：PA14(TX) / PA15(RX)

按键低电平有效（内部上拉），另一端接 GND。

使用：

1. 上电后搜索并连接 BLE 设备 HID MobileController。
2. 连接成功后即可使用按键：方向键为滑动，中间键为点击，上/下长按为音量。
3. 拍照：按住拍照键，用方向键把触摸点移动到相机快门位置（校准位置），松开后约 5 秒自动保存。
